# 触觉硬件

设备型号：ONE1000。

## 作用与边界

`one1000_tactile_node` 使用 Python 标准库以 115200 8N1、非阻塞方式读取全迹 ONE1000 串口，把雷达摸头或 UWB 近距离检测转换成统一的 `EVT_TACTILE_HEAD_PET`，同时发布硬件诊断状态。

它只产生触觉事件，不直接修改情绪；`emotion_engine_node` 接收事件后应用 Joy +25、Calm +15、Excite +5 的基础映射。需求节点接收同一事件但不修改需求。

## ROS2 参数

| 参数 | 默认 | 规则 | launch 是否暴露 |
|---|---|---|---|
| `serial_port` | `/dev/ttyUSB1` | 非空路径 | 是 |
| `detection_mode` | `distance` | 只允许 `distance` 或 `radar` | 是 |
| `distance_threshold_cm` | 10.0 | 有限正数，实际判断严格小于 | 是 |
| `auto_start_sentry` | true | radar 模式是否自动配置并启动 | 是 |
| `touch_threshold` | 30 | 整数 1..65535 | 是 |
| `command_interval_seconds` | 0.3 | 有限且不小于 0.2 | 否，可直接给节点参数 |
| `touch_cooldown_seconds` | 2.0 | 有限非负真实秒 | 是 |
| `stop_sentry_on_shutdown` | true | 启动过哨兵时退出前发送停止 | 否，可直接给节点参数 |

所有参数都是只读启动参数。

## 串口帧

```text
55 AA | sequence:uint8 | tlvTotalLength:uint16_le | TLV... | crc16:uint16_be
TLV = type:uint8 | valueLength:uint8 | value[valueLength]
```

- CRC 使用 CRC16-XMODEM，多项式 `0x1021`，初始值 0。
- CRC 只覆盖全部 TLV 字节，不覆盖帧头、序号和外层长度。
- 默认最大 TLV 总长度为 1024，合法范围 2..65535。
- 解析器支持任意串口分片、帧头前噪声、多 TLV 和 CRC 错误后的单字节滑动重同步。
- 特殊兼容：C5 内层 Length 声明 33、外层实际剩余恰好 38 字节时，按 38 字节解析，用于部分 5.1.x 固件。

## TLV 类型

| 类型 | 含义 | Value 格式 |
|---:|---|---|
| `0x00` | 设备命令响应 | `responseType:uint8, status:uint8` |
| `0x4A` | 哨兵控制命令 | `0x03` 清缓存、`0x04` 启动、`0x05` 停止 |
| `0x54` | 哨兵/摸头状态 | `<BfH`，7 字节小端 |
| `0x57` | 摸头阈值命令 | `uint16_le` |
| `0x59` | 心跳 | counter、rangingStatus、radarStatus，各 uint8 |
| `0xC5` | 定位结果 | 固定 `<IIIHfffB`，再接 RSSI 和可选质量字段 |

## 雷达检测模式

0x54 的 `rawStatus`：

- `0xFF`：无效检测，不视作松手，保留上一次可靠触摸状态。
- bit 0：`livingBodyDetected`。
- bit 1：`headTouchDetected`。
- 后续 float 为 `maxRadarValue`，uint16 为 `livingBodyFirstIndex`。

只在有效 `headTouchDetected` 的上升沿触发一次。连续高电平不重复；检测到松手后可以重新进入，但仍受冷却时间限制。

radar + 自动启动时，在首次心跳到达或打开串口 500 ms 后依次排队：

1. 0x57 设置摸头阈值。
2. 0x4A/0x03 清哨兵缓存。
3. 0x4A/0x04 启动哨兵。

命令间隔默认至少 0.3 秒。只有实际发送过启动命令且 `stop_sentry_on_shutdown=true`，退出时才等待必要间隔并发送 0x4A/0x05。

## 距离检测模式

0xC5 固定字段：

| 字段 | 类型 |
|---|---|
| `syncCounter` | uint32 |
| `anchorMacId` | uint32 |
| `beaconId` | uint32 |
| `beaconType` | uint16 |
| `distanceMeters` | float32 |
| `angleDegrees` | float32 |
| `pitchDegrees` | float32 |
| `rssiLength` | uint8 |

之后读取 `rssiLength` 个 int8 到 `rssiValues`；剩余最多前 4 个 int8 依次是 `rxPower`、`rssiFirstPath`、`rssiNonFirstPath`、`rssiBluetooth`，第 5 个字节是无符号 `positionConfidence`。

触发条件：

```text
0 < distanceMeters × 100 < distance_threshold_cm
```

- 第一次进入阈值立即触发。
- 持续处于阈值内时，每满 `touch_cooldown_seconds` 再触发。
- 距离达到或超过阈值会离开触摸态，下次进入立即触发，不受上一次冷却限制。
- 距离等于 0 视作无效，不触发；当前实现也不会把已有触摸态清除。
- 距离、角度、俯仰中任一为 NaN/Infinity，整个定位记录拒绝。

## 触觉输出

两种模式都发布 `/perception/tactile_event`，公共字段：

| 字段 | 值/类型 |
|---|---|
| `schema_version` | `"1.0"` |
| `timestamp` | 墙上 Unix 秒 |
| `event_type` | `EVT_TACTILE_HEAD_PET` |
| `source` | `ONE1000` |
| `touchState` | `STARTED` |

distance 模式补充 `sensorType=UWB_DISTANCE`、`detectionMethod=DISTANCE_THRESHOLD`、米/厘米距离、阈值、anchor/beacon 标识和可空置信度。radar 模式补充 `sensorType=UWB_RADAR`、原始状态、活体位和雷达调试值。

## 诊断状态

`/one1000/status` 每真实秒发布。`connected` 在串口已打开且以下任意一种最近年龄不超过 2.5 秒时为 true：

- 收到有效 0x59 心跳。
- 收到任意通过 CRC/TLV 校验的数据包。
- 收到任意 UART 字节，即使只是调试文本。

### `detection`

| 字段 | 类型 |
|---|---|
| `mode` | `distance`/`radar` |
| `distanceThresholdCentimeters` | number |
| `distanceTouchActive` | boolean |

### `protocol`

| 字段 | 类型/说明 |
|---|---|
| `active` | 有最近有效协议包 |
| `uartActive` | 有最近 UART 字节 |
| `receivedByteCount` | 启动后总字节数 |
| `lastByteAgeSeconds` | number/null |
| `validPacketCount` | 有效包总数 |
| `positionPacketCount` | 含 C5 TLV 的包总数 |
| `lastPacketAgeSeconds` | number/null |

### `commands`

| 字段 | 类型/说明 |
|---|---|
| `startupCommandsQueued` | boolean |
| `sentCount` | 已发命令数 |
| `responseCount` | 已解析设备响应数 |
| `lastResponse` | null 或 `{responseType, status, success}`；status=0 为成功 |

### `heartbeat`

可空。包含 `counter`、`ageSeconds`、两个原始状态、可读状态和 `radarActive`。测距状态映射：0x03 DEINITIALIZED、0x05 ACTIVE、0x06 TIMEOUT；雷达状态 0x06 映射为 RANGING_CONFLICT_TIMEOUT，其余未知值为 UNKNOWN。

### `sentryStatus`

可空。包含 `ageSeconds`、`rawStatus`、`detectionValid`、`livingBodyDetected`、`headTouchDetected`、`maxRadarValue`、`livingBodyFirstIndex`。

### `position`

可空。包含所有定位解析字段，另含 `distanceCentimeters`、`withinTouchThreshold` 和 `ageSeconds`。RSSI 数组输出为 JSON 数组，可选质量字段没有数据时为 null。

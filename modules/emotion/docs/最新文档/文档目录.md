## 文档原则

本目录只依据当前仓库的 Python 源码、`configs/*.yaml`、ROS2 launch 文件、包元数据和测试契约重新整理，不继承或引用本目录之外的历史文档。

事实优先级如下：

1. 节点和核心系统实际执行的源码。
2. 当前加载的配置值。
3. 自动化测试明确覆盖的边界。
4. 代码中没有入口或没有执行逻辑的配置，只标记为“已配置但未接入”，不视为已实现需求。

# 字段

## 公共格式

| 项目 | 实际格式 |
|---|---|
| ROS2 类型 | `std_msgs/msg/String` |
| 载荷 | `String.data` 中的 UTF-8 JSON 对象 |
| `schema_version` | 字符串，例如 `"1.0"`、`"2.0"` |
| `timestamp` | 浮点 Unix 秒；本仓库输出使用墙上时间，不是虚拟时间 |
| `event_type` | 字符串事件名 |
| `timeContext` | 时间、需求和情绪节点输出中的虚拟时间上下文对象 |
| 数值范围 | 需求、情绪、性格统一限制在整数 `0..100` |
| 空值 | 未配置阈值或尚无硬件数据时输出 JSON `null` |

输入适配器只接受 JSON 对象。非法 JSON、数组、数字、字符串标量会被转换为空对象并忽略。除 `/simulation/time_state` 和 `/behavior/result_event` 的专项校验外，当前代码不强制验证输入的 `schema_version`、`timestamp` 或额外字段。

## 命名现状

协议同时存在两种命名：

- 新版通用字段偏向 snake_case：`schema_version`、`event_type`、`action_type`、`result_type`。
- 领域对象和部分兼容字段使用 camelCase：`triggerThreshold`、`previousLevel`、`foodType`、`timeContext`。

不得自行把输出字段改成另一种写法。输入仅在源码明确声明时支持别名，详见[输入](输入.md)。

## 行为结果枚举

输入 `result_type` 转大写后只允许：

- `STARTED`
- `COMPLETED`
- `FAILED`
- `INTERRUPTED`
- `CANCELLED`
- `TIMEOUT`

内部情绪映射名是另一套值：`DemandSatisfied`、`DemandUnsatisfied`、`ActionInterrupted`。外部不要把这三个内部名填进 `result_type`。

## 比较操作符

| 值 | 含义 |
|---|---|
| `gt` | 大于 |
| `gte` | 大于等于 |
| `lt` | 小于 |
| `lte` | 小于等于 |
| `eq` | 等于 |

需求阈值目前全部使用 `gt`，所以“等于阈值”仍属于较低等级；情绪阈值目前全部使用 `gte`，所以“等于阈值”即触发。

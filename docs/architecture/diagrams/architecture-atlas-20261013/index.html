S04　选择与抢占资格：先比较语义顺序

回到目录 ↑

候选池先筛可运行候选，抢占资格再按优先级键及同级规则判断，中断策略另行检查。

图中“池中保留”指 select_best 的 can_run / 冷却筛选未选中者。候选进入运行层后仍会复核；复核失败可丢弃 pending，不等同于所有拒绝都永久排队。

比较项精确规则
候选池字典序priority_level ↑ → semantic_rank ↑ → modality_rank ↑ → behavior_rank ↑（缺省 sub_priority）→ emotion_priority ↑ → value ↓ → created_at ↓。不是加权总分，也不是 FIFO。
抢占键 K只取 (priority_level, semantic_rank, modality_rank, behavior_rank)。新 K 更小进入中断门；更大不抢占。
新 K = 当前 K同 interaction_id 且 session_preempt_rank 更小，或 value 差值 ≥15，才有抢占资格。
显式例外已授权新语音命令替换 audio_direct + until_preempted 的长语音任务；硬件唤醒可替换跟随 / 独自玩耍。仍须通过 S05 中断门。
Lv0 → Lv6安全（含 Energy rest / recharge）→ 外部交互 → 紧急生理 → 普通生理 → 心理需求 → 情绪表达 → idle。
同 Lv1 的含义视觉安全 semantic_rank=0，具体语音=1，唤醒=2，普通默认=3。来源 modality 在语义之后比较。

S07　抢占时序：先取消旧 Goal，再交接新 Goal

回到目录 ↑

取消 ACK 只确认请求接收，BT 保留旧 Goal 与替换候选直到真实终态返回。

S08　Goal 生命周期：发送、运行、取消等待、终态

回到目录 ↑

Goal 生命周期与业务结果不同，超时请求取消但不伪造设备停止。

TERMINAL 是生命周期阶段，不等于成功。业务结果及原因、超时请求标记、适配器恢复限制仍需保留。图示合并了未成功下发的终止路径；不是把发送失败当成成功 Result。

不同时间约束负责什么
TTL候选在队列中的期限；Needs 的 TTL=0 依靠权威状态作废，不按时间过期。
timeout本轮执行预算；到期请求取消并等真实终态。
lease / hold长任务和语音会话的保活；到期按对应服务规则处理。
cooldown本次完成后限制同名行为再次启动；不是执行锁。
停止确认期限导航 / 局部运动确认旧任务结束的预算；超限进入不确定 / 恢复限制。

靠近能力的三种接口

C01　靠近能力：场景选策略，Action 固定执行路径

回到目录 ↑

同一靠近意图对应三个显式接口；场景选择方式，Action 检查前置条件与能力，不暗中降级。

根据 2026-10-13 的场景要求补充本设计。approach_visual / approach_local / approach_map 与 ApproachRequest 是建议的逻辑端口名称，不是已发布的 ROS endpoint / IDL；本次只更新设计，不新增运行接口，不改变默认路由。

BT 的场景配置明确策略及允许的阶段组合；Action 校验所选方式能否运行。保留现有 ExecuteBehavior 外部契约，是否新增独立 ROS Action 应在消费方和实现边界明确后单独决定。三种接口各自可调用，共享外层任务模型，不把三种执行算法揉成一个控制器。

策略输入和依赖完成依据
visual_servo · 纯视觉持续的锁定目标观测；图像偏差 + 明确距离模式。无路径规划 / SLAM 依赖。图像对齐与指定距离依据稳定满足；停止证据单独记录。
local_nav · 局部导航视觉定位 → 相机三维点 → base / odom；局部障碍、里程计、TF；可冻结局部终点或持续更新同一目标。达到局部容差 / 保持距离要求，局部任务终态与停车确认。
map_nav · 地图导航视觉定位 → map 坐标安全终点；或明确选择命名地点。地图、全局定位、TF、Nav2 必须可用。当前目标版本已到达；导航终态和停止依据满足，不以“已提交”算完成。

统一任务契约（建议）

字段组规则
请求身份contract_version、request_id、父 goal_id、interaction_id；每次尝试另有 attempt_id / generation。相同 request_id 的重试查询原任务，不重复启动运动。
策略strategy 必填：visual_servo / local_nav / map_nav。运行开始后固定；不得因深度 / TF / 导航失败自动换策略。
目标引用target_kind 区分 visual_track / local_pose / map_pose / named_place。视觉引用必须保留 vision_epoch、target_id、类别、观测来源、原始 stamp；角色授权由上层传递，名称不能替代身份。
更新策略target_update_policy 显式选 snapshot 或 tracked。快照冻结终点；跟踪维持同一身份并限制更新率、位移 / 角度变化和几何时效。策略不支持某模式时拒绝。
距离与到达metric 模式使用米；image_ratio 模式使用归一化图像量。stand_off_m 只在有效度量几何下有含义。容差、朝向、hold 时间分开定义。
预算与边界一个端到端 deadline，分配获取目标、几何、执行与停止确认预算；配置最大行程、速度、障碍要求。切换策略不重置总预算。
反馈保持 goal / attempt / target 关联，报告 ACQUIRING / LOCALIZING / RUNNING / STOPPING / RECOVERY_REQUIRED、距离值与单位、观测年龄、有效策略与实际能力。
终态与证据outcome、reason、effective_strategy、target_ref、arrival_evidence、stop_evidence。停止证据采用 confirmed / unconfirmed / unknown；没有设备证据时不伪造 confirmed。
错误区分建议区分 TARGET_LOST、STALE_OBSERVATION、GEOMETRY_UNAVAILABLE、FRAME_UNAVAILABLE、MAP_MISMATCH、BLOCKED、TIMEOUT、CANCELED、STOP_UNCONFIRMED / RECOVERY_REQUIRED；不是现有全模块已统一的枚举。

策略切换与仲裁

同一靠近任务运行时只允许一个策略持有运动控制权。场景若显式允许 map_nav → visual_servo 等分阶段组合：BT / 编排器请求结束旧阶段 → 等待旧任务匹配终态及停止确认 → 重新校验目标和坐标 → 使用新 attempt_id 开始下一阶段。取消 ACK、超时和发送零速都不能单独作为交接完成依据。停止未知时进入恢复限制，不启动新控制器。

优先级仲裁仍由 BT 决定，具体停止由 Action 及对应适配器执行。三个策略都沿用 S04–S10 的抢占与取消原则；未来统一运动所有权门见 S13。能力选择表不能取代当前尚未完成的底盘出口治理。

C03　局部导航靠近：视觉定位 → 局部坐标 → 局部规划

回到目录 ↑

同帧视觉与深度得到三维目标，经 TF 转为 base / odom，交给局部运动服务，不强依赖全局 map。

snapshot：把基于该次观测计算的安全终点固定到 odom，再使用 mode=move；base 相对固定点只在接受时转换一次，不能每帧跟着机器人移动。tracked：使用同一 source / target_id 的 TargetObservation，通过 mode=approach 持续更新距离；持续陪走另属 follow 的语义。

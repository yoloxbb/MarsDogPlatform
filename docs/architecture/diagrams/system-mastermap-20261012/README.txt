MarsDog 全量系统总图
====================
这版将原图册的流程汇入一张连续画布：23 个分区、942 个节点、530 条显示连接。
画布：21840 × 28784 矢量坐标；可无限清晰缩放，不是截图拼接。

打开 MarsDog全量系统总图.html。文件离线可用，无 CDN、网络请求或依赖安装。
滚轮缩放，拖动画布；“主流程”“全图”、模块下拉框和左下角鹰眼可定位。
搜索事件、行为名、动作单元或条件；点击节点查看规则、代码出处和直接上下游。
点击“关联目录”可沿命令 → 路由 → 行为模板 → 动作单元跳转。
为避免数百条目录绑定线覆盖流程，目录的绑定关系通过点击导航表达。
图上的实线/虚线类型并非独立的执行保证；明确标注“待接入 / 建议”的部分尚未实施。

已展开：
- 听觉、视觉、内部需求与情绪、行为树、动作、SLAM 导航与局部运动；
- 输入授权与去重、候选、优先级、抢占门、中断策略、取消响应与真实终态；
- 唤醒会话、目标锁、人物接近断点、导航恢复限制、反馈与需求结算；
- 全部 125 条声明路由、74 个行为模板及 134 个阶段、183 个动作单元、82 个语音命令。

其他格式：

- .svg：静态矢量总图。浏览器或矢量编辑器可打开，不含交互侧栏。
- provenance.json：本图的数据来源、源文件与产物 SHA-256。

# Lite3 本机开发验收目标

2026-09-29 用户确认：首个目标为 Lite3，目前模块分别启动，需要统一入口；
先在本机验收，依赖与 NPU 可以使用 CPU 替代。

本轮交付是可安装、可启动、可关闭、可回放验证的 Lite3 本机软件组合。
优先保留现有 CPU 后端；当前没有模型文件、相机/麦克风、底盘或真实 Nav2
设备输入的部分使用显式标记的开发替身，不伪称硬件或模型推理验收。
本机 profile 禁用真实运动输出，不修改旧生产默认配置、底盘协议和控制语义。

统一入口应分别提供 prepare/build、doctor、up/down 或前台 Ctrl-C、smoke。
所有模块独立解释器；进程/端点/类型/状态有报告；退出不遗留子进程。
固定 Robotics/vendor 来源、构建 DAG、原历史、模型/硬件缺项和未来生产边界。

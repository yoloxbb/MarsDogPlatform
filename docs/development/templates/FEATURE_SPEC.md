## 输入和生命周期

| 项目 | 约定 |
| --- | --- |
| 触发及授权 | 事件、命令身份、会话与去重 |
| 感知事件去向 | 按 event_type 分别列出直驱映射与情绪规则；仅直驱 / 仅影响情绪 / 两者兼有 / 不涉及；双路径写明即时反应、后续触发与去重预期 |
| 行为来源 | 感知直驱 / 内部触发；具体 source；情绪或需求状态的权威；不可用动作模板名称代替来源 |
| 仲裁与有效性 | 单独指定优先级、中断策略、TTL、状态恢复和会话关闭规则；两类共用统一仲裁 |
| 前置条件 | 能力、设备、目标、定位和配置 |
| 目标绑定 | 身份、epoch、坐标系、时间戳与新鲜度 |
| 执行路径 | BT 行为、Action 阶段及 Unit、导航或外部能力 |
| 资源 | 底盘、音频、显示等资源占用与释放 |
| 结束与取消 | 成功证据、抢占条件、ACK 与终态、停止确认 |
| 失败及恢复 | 无目标、过期、超时、进程故障、结果未知 |
| 内部状态 | 是否进入既有需求映射；结算证据与去重 |

## 接口变化

列出生产者、消费者、协议版本、固定样例、兼容方式与旧入口退出条件。无变化时说明复用哪些接口。新错误码、坐标转换或时间约定必须同时给出消费方行为。
